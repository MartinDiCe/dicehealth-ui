# DiceHealth

Landing publica del vertical de salud de DiceProjects.

## Posicionamiento

**La Plataforma de Gestion Clinica para instituciones de salud.**

Centraliza pacientes, agenda, historia clinica, tratamientos, expedientes y seguimiento clinico desde una unica plataforma con IA, automatizaciones e integracion completa.

DiceHealth no debe venderse como turnero, agenda medica o historia clinica aislada. Debe comunicarse como una plataforma de gestion clinica construida sobre DiceProjects Core.

## Publico objetivo

- Clinicas
- Consultorios
- Centros medicos
- Odontologia
- Veterinarias
- Psicologia
- Kinesiologia
- Nutricion
- Centros de diagnostico
- Centros de rehabilitacion

## Entidad principal

La entidad principal es el **paciente**.

En veterinaria:

Tutor -> Mascotas -> Historia clinica -> Tratamientos -> Seguimiento.

## Flujo principal

Paciente -> Turno -> Confirmacion -> Atencion -> Historia clinica -> Tratamiento -> Seguimiento -> Dashboard -> Copiloto clinico.

## Modulos

- Agenda clinica: profesional, consultorio, especialidad, equipo, sede, confirmacion, reprogramacion y lista de espera.
- Pacientes: datos, tutor, familia, cobertura, contacto, alertas y documentacion.
- Historia clinica: evoluciones, diagnosticos, indicaciones, estudios, adjuntos y auditoria.
- Tratamientos: planes, sesiones, controles, seguimiento y alta.
- Medicamentos e insumos: vacunas, medicamentos, dosis, via, frecuencia, lotes, vencimientos y vinculo con stock clinico/warehouse.
- Expediente clinico: historia, estudios, consentimientos, recetas, presupuestos, informes, documentacion y derivaciones.
- Scoring: riesgo, urgencia, ausentismo, prioridad y continuidad.
- Dashboard: pacientes atendidos, tratamientos activos, ausentismo, ocupacion, profesionales, consultorios y pacientes pendientes.
- Copiloto clinico: pacientes que deben volver, tratamientos activos, consultorios disponibles, prioridades y agenda libre.

## Datos demo

La demo debe verse como una institucion funcionando y nunca vacia.

Debe incluir profesionales medicos, odontologos, psicologos y veterinarios; pacientes adultos, ninos y mascotas; tratamientos de ortodoncia, kinesiologia, vacunacion, psicologia y rehabilitacion.

En veterinaria debe incluir pacientes animales con vacunas, medicacion indicada, estudios requeridos, recomendaciones por especie y consumo de insumos/medicamentos integrable con Warehouse.

## Estilo visual

Profesional, moderno, mucho blanco, azules, indicadores clinicos y dashboard ejecutivo.

## Mensaje comercial

DiceHealth no es un sistema de turnos. Es una Plataforma de Gestion Clinica que conecta pacientes, agenda, historia clinica, tratamientos, expedientes y seguimiento para mejorar la atencion y la operacion de instituciones de salud.
